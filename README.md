# Part-3
# Lwera's Kicks - E-Commerce Website (WEDE5020 POE)

## Project Overview
Lwera's Kicks is an interactive e-commerce web platform showcasing performance running shoes, basketball sneakers, and lifestyle kicks.

---

## Part 3 Changelog & Enhancements

### 1. Feedback Corrections from Part 2
* **Navigation & Mobile Responsiveness:** Adjusted navbar break-points and padding across tablet and mobile viewports.
* **Image Accessibility:** Ensured all product imagery contains descriptive `alt` attributes for screen readers and SEO.

### 2. JavaScript Enhancements
* **Dynamic Search & Filtering:** Implemented realtime keyword search and category dropdown filters on `products.html`.
* **Image Lightbox Gallery:** Added modal lightbox view allowing users to click product thumbnails for an enlarged view.
* **Interactive Accordion:** Implemented animated collapse/expand panels for FAQs on the About page.

### 3. SEO Optimization
* Added page-specific meta descriptions, keywords, author metadata, and Open Graph protocol tags across all HTML headers.
* Configured `robots.txt` in the root folder.
* Created a complete `sitemap.xml` mapping site URLs.

### 4. Form Functionality & Client-Side Validation
* **`enquiry.html` Form:** Includes JavaScript regex validation for email, South African phone numbers (`082xxxxxxx`), and quantity selection. Dynamically calculates and displays estimated order costs and availability upon validation.
* **`contact.html` Form:** Validates contact information and user message body before rendering confirmation and a `mailto:` link for local email client submission.
